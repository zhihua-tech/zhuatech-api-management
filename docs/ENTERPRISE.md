# 企业集成与 API 管理平台企业能力

## 领域覆盖

- **API目录**：统一登记版本、协议、负责人和生命周期
- **应用接入**：管理消费应用、凭据与授权范围
- **认证策略**：配置JWT、签名、OAuth2和IP白名单
- **流量策略**：执行限流、熔断、降级与配额
- **接口编排**：完成协议转换、字段映射和服务编排
- **订阅管理**：审批订阅并控制环境和有效期
- **运行监控**：跟踪成功率、延迟、错误码和依赖
- **告警处置**：告警分派、升级和复盘
- **调用审计**：保留调用、策略变更与管理员操作证据

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业集成与 API 管理平台关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `GATEWAY`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
